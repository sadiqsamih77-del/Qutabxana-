# School System - Mobile Web Version

This is a mobile-friendly browser version of the C# Windows Forms School System.

Features:
- Administrator password creation/login
- Student add, edit and delete
- Search by ID/name
- Grade filter
- CSV export
- Statistics by grade
- Activity log
- Change password
- Responsive design for Android phones and computers

## Run on a computer
Open `index.html` in a modern browser.

## Put it online
Upload `index.html` to a static web host such as GitHub Pages, Netlify, Vercel, or Cloudflare Pages.
After publishing, open the generated HTTPS address on your phone.

## Important
This version stores students and the administrator password in the browser's localStorage. It is suitable for a simple university/demo project, but it is NOT a secure multi-user production system. For a real shared system, a server API and database should be added.
